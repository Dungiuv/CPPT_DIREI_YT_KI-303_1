# Консольний звіт

## Призначення
Програма читає дані про поїздки автопарку з файлу `data/input.csv`, перевіряє їх на коректність (фільтрує биті рядки з виведенням попереджень), обчислює ключові показники (сумарний кілометраж, середню витрату палива на 100 км, найбільшу поїздку) та формує звіт у консоль і файл `out/report.txt`.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою. Файл кодують
у UTF-8.

## Збірка та запуск
```text
mvnw.cmd verify
mvnw.cmd package
java -jar target/labs-1.0.0.jar
java -jar target/labs-1.0.0.jar --version
java -jar target/labs-1.0.0.jar --help
java -jar target/labs-1.0.0.jar --input data/input.csv --output out/report.txt
```
Для коротких опцій використовуйте `-h`, `-i` та `-o`. Шляхи також можна задавати у форматі `--input=PATH` і `--output=PATH`.
На macOS та Ubuntu замість `mvnw.cmd` використовуйте `./mvnw`.
